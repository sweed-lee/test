## Falling Blocks Dodge

HTML5 Canvas 躲避方块小游戏，使用原生 HTML/CSS/JS 编写，无需任何依赖或构建步骤。坚持越久得分越高，方块会越来越快，考验操作与反应力。

### 如何运行（Windows / macOS / Linux）
1. 在仓库根目录启动本地服务器：
   ```bash
   python -m http.server 8000
   ```
2. 打开浏览器访问 [http://localhost:8000](http://localhost:8000)，即可开始游戏。

> 如果系统同时安装了 Python2/3，可改用 `python3 -m http.server 8000`。

### 操作说明
- 开始：空格键或点击“开始”按钮
- 移动：方向键 ←/→ 或 A/D
- 暂停/继续：键盘 `P` 或按钮
- 重开：键盘 `R` 或按钮

### 游戏特点
- 计分系统：生存时间越久得分越高，并在顶部实时显示。
- 难度提升：下落方块数量与速度会随时间逐渐提高。
- 完整状态控制：支持开始、暂停/继续、重开以及自动失焦暂停。
- 自适应画布与视觉反馈：加入网格背景、半透明提示卡片和圆角块体，便于快速上手。
