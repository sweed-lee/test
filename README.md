# Canvas 躲避方块小游戏

一个零依赖（原生 HTML/CSS/JS）的 HTML5 Canvas 小游戏，玩家控制蓝色方块躲避不断加速与增多的红色障碍物。游戏具备开始、暂停、重开控制以及随时间增长的计分与难度曲线。

## 快速开始

> 适用于 Windows / macOS / Linux

```bash
python -m http.server 8000
```

然后打开浏览器访问：<http://localhost:8000>

如果你系统同时安装了 `python` 与 `python3`，任选其一即可。

## 文件结构

- `index.html`：页面结构与按钮。
- `style.css`：自适应 UI 样式与暗色主题。
- `game.js`：Canvas 渲染、输入、碰撞检测与难度/计分逻辑。
- `README.md`：运行指南（当前文件）。

## 操作说明

- 使用方向键或 `WASD` 在画布底部左右移动玩家。
- `开始`：首次启动或暂停后继续。
- `暂停`：临时停止（失焦也会自动暂停）。
- `重开`：立即重置分数与难度并重新开始。
- 按 `Space` 也可在开始/暂停之间切换，或在失败后快速重开。

## 游戏机制亮点

- 随时间线性提高障碍物下落速度与生成频率。
- 计分随存活时间持续累积。
- 结束时画布中央会给出提示，点击重开或按空格立即再战。
