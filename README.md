# Canvas 躲避坠落方块小游戏

一个无需依赖、可直接在浏览器中游玩的 HTML5 Canvas 小游戏。使用方向键或 WASD 控制绿色方块，躲避不断加速的红色障碍，努力生存并冲击高分。

## 功能亮点
- 原生 HTML/CSS/JS，无任何构建步骤
- 支持开始、暂停、重开
- 难度随生存时间自动提升（障碍更快、更密集）
- 实时分数、难度倍率与状态提示
- 自动在标签页隐藏时暂停，避免错过操作

## 运行方式（Windows/macOS/Linux 通用）
1. 打开终端并进入仓库根目录：
   ```bash
   cd /path/to/repo
   ```
2. 启动一个本地静态服务器（Python 自带）：
   ```bash
   python -m http.server 8000
   ```
3. 在浏览器访问 [http://localhost:8000](http://localhost:8000) 即可开始游戏。

> 如果 8000 端口被占用，可以换成任意空闲端口，但需同步修改访问地址。

## 操作说明
- `方向键` 或 `WASD`：移动
- `空格键`：在运行中暂停，再次按下继续；在暂停/结束时按下开始
- `开始/暂停/重开` 按钮：同名功能
