# Canvas 躲避方块小游戏

一个使用原生 HTML/CSS/JavaScript 构建的 HTML5 Canvas 小游戏。玩家控制发光方块在画布中移动，躲避自上而下的障碍。生存时间越长，速度越快、得分越高。

## 功能亮点
- 无任何依赖，直接在浏览器中运行。
- 支持开始、暂停/继续、重开三种控制按钮。
- 键盘方向键或 WASD 控制移动。
- 分数会随生存时间以及成功躲避的障碍累积。
- 难度随时间自动提升：障碍下落更快、生成更频繁。

## 运行方式（Windows / macOS / Linux）
1. 在仓库根目录打开终端。
2. 启动本地静态服务器：
   ```bash
   python -m http.server 8000
   ```
3. 打开浏览器访问：<http://localhost:8000>
4. 页面加载后点击“开始”，即可使用方向键或 WASD 玩游戏。

## 项目结构
- `index.html`：页面结构与按钮。
- `style.css`：布局与视觉样式。
- `game.js`：游戏主循环、碰撞、难度与输入处理。
- `README.md`：说明文档（即本文件）。

## 自定义建议
- 可在 `game.js` 中调整玩家速度、障碍大小或难度增长曲线。
- 如需更丰富的音效或素材，可直接在现有文件基础上扩展。
