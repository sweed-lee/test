# Meteor Dodge

Meteor Dodge 是一个使用原生 HTML/CSS/JavaScript 编写的 HTML5 Canvas 小游戏。你需要操控发光的小飞船穿梭在流星雨中，存活得越久、得分越高，陨石的坠落速度与数量也会随时间不断提升。

## 玩法概览

- **开始/暂停/重开**：顶部按钮或覆盖层按钮可随时开始、暂停或重新开始；也可以按下空格键暂停/恢复。
- **操控方式**：
  - `Left / Right Arrow` 或 `A / D` 控制水平移动。
  - `Up / Down Arrow` 或 `W / S` 控制垂直微调。
- **计分与难度**：存活时间越久，难度系数越高，陨石速度、刷新频率随之增长，得分也会更快累积。

## 运行方式 (Windows / macOS / Linux 通用)

1. 确保系统内置或已安装 Python 3。
2. 在项目根目录启动本地静态服务器：
   ```bash
   python -m http.server 8000
   ```
3. 打开浏览器访问 <http://localhost:8000> 即可开始游玩。

无需任何构建工具或额外依赖，直接通过浏览器即可运行。祝你玩得开心！
